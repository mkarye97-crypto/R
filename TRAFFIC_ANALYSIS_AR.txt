تحليل اتصال QUREO — وضع التشخيص
================================

أثناء تشغيل main.py، يتم تسجيل طلبات API التعليمية التي ينفذها البرنامج وردود الخادم في:
data/api_traffic_audit.jsonl

يسجل كل سطر:
- وقت الطلب والطريقة والمسار.
- جسم الطلب بعد تنقيح الحقول الحساسة.
- HTTP status.
- جسم الرد بعد تنقيح الحقول الحساسة.

لا يتم تسجيل:
- Authorization أو Cookies أو access/refresh/id tokens.
- طلبات OAuth.
- رد /api/study/students/me الذي قد يحتوي بيانات الحساب.
- كلمة المرور أو ترويسات الجلسة.

حدود مهمة:
- هذا يسجل فقط حركة HTTP التي تنفذها الأداة عبر requests.Session؛ لا يراقب كل تطبيقات الهاتف أو حركة الشبكة الأخرى.
- تحليل رد السؤال والاختيارات لا يكشف مفتاح الإجابة بالضرورة. غالبًا لا يرسل الخادم الإجابة الصحيحة قبل تقديم الاختبار.
- HTTP 200 لقبول إجابة لا يثبت صحتها. الصحة لا تثبت إلا من نتيجة رسمية تحتوي correct=true بعد التقديم.
- لذلك لا تختار الأداة إجابة عشوائية ولا تدّعي ضمان 100%. إذا لم توجد إجابة مرجعية مؤكدة، يجب مراجعتها بدل التخمين.

بعد تشغيل الأداة، يمكن مشاركة api_traffic_audit.jsonl بعد مراجعته وحذف أي بيانات شخصية متبقية. لا تشارك ملفات Cookies أو HAR الخام.
