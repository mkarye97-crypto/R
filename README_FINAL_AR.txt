MOODY QUREO — FINAL REQUESTS RUNNER
===================================

هذه النسخة تجمع:
1) تسجيل الدخول بحسابك من خلال مطالبة تفاعلية؛ لا تحفظ كلمة المرور أو Cookies.
2) قراءة حالة الفصول والمحاضرات من QUREO وتخطي المكتمل منها.
3) إكمال المحاضرات غير المكتملة حسب بيانات API.
4) قراءة اختبار/مراجعة الفصل.
5) مطابقة الأسئلة باستخدام معرف الفصل + معرف السؤال من قاعدة محلية تضم 266 سجلًا.
6) إرسال الاختيارات عبر choice_id المطابق تمامًا، وإجابات الوصف من السجل المطابق لمعرف السؤال.
7) قراءة نتيجة QUREO بعد الإرسال وحفظها.
8) تسجيل حركة API المنفذة من الأداة في data/api_traffic_audit.jsonl بعد تنقية الحقول الحساسة.

تنبيه مهم:
- بنك الإجابات مصدر خارجي غير رسمي، وموسوم داخل قاعدة البيانات بأنه غير متحقق من المنصة.
- تطابق معرف السؤال لا يثبت وحده صحة الإجابة؛ نتيجة QUREO هي مرجع التحقق.
- الأسئلة التي لا يوجد لها سجل مطابق أو لا يمكن ربط اختيارها بدقة تُترك دون إجابة؛ لا يوجد اختيار عشوائي.
- بعض الفصول/أنواع التقييم قد تختلف عن عينات HAR المتاحة. عند اختلاف الاستجابة، تحفظ الأداة JSON الخام وتتوقف/تسجل الخطأ بدل تخمين API.
- لا توجد ضمانة 100%، ولم يتم إجراء اختبار حي بحساب المستخدم من بيئة البناء هذه.
- لا تشارك ملفات Cookies أو Tokens أو كلمات المرور. لا ترفع مجلد data كاملًا إذا احتوى على بيانات حسابك؛ شارك تقارير الأخطاء المنقحة فقط.

التشغيل على Termux:
-------------------
1. فك الضغط.
2. ادخل المجلد:
   cd MOODY_QUREO_REQUESTS_REFERENCE_MATCHER_v5_3
3. ثبّت المتطلبات:
   pip install -r requirements.txt
4. تشغيل معاينة بدون إرسال إجابات:
   python main.py --from-level 5 --to-level 6 --preview-only
5. تشغيل فعلي بعد مراجعة المعاينة:
   python main.py --from-level 5 --to-level 6
   اكتب SUBMIT عند مطالبتك بالتأكيد.

لتشغيل كل الفصول:
   python main.py

الملفات المهمة:
- data/question_answer_database.json : قاعدة الأسئلة والإجابات (266 سجلًا).
- data/run_report.json : ملخص التشغيل.
- data/api_traffic_audit.jsonl : سجل API منقح.
- data/assessment_<chapter>_answers.json : الإجابات التي أرسلت/المطابقات.
- data/assessment_<chapter>_server_result.json : نتيجة QUREO.

ملاحظة عن سجل الاتصالات:
الأداة تسجل فقط الطلبات التي تمر عبر دالة API الخاصة بها، ولا تلتقط كل اتصالات الهاتف أو التطبيقات الأخرى.
